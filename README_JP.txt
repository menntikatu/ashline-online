ASHLINE: BLACK CELL — 待機画面対応版

動作:
1. ゲームを開き、マップを選ぶ
2. 「部屋を作る」を押すと待機画面のまま部屋番号が表示されます
3. 友達は部屋番号を入力して「番号で参加」を押します
4. 1人で遊ぶ場合、友達を待たずに「プレイ開始」を押すとAI敵ありのソロミッションが始まります
5. 友達がオンライン接続して参加している場合は「プレイ開始」で対人戦を開始します

注意:
- ZIPを展開し、フォルダー内のファイルを同じ場所に保ってください。
- Renderのサーバーを更新する場合は、index.html / server.js / package.json をリポジトリの同じ階層に置いてください。
- 今回の修正は待機画面と開始フローです。Renderの公開サーバーが正常に動作しているかは、RenderのLogsと /health で確認してください。
- 3D表示にはインターネット接続が必要です。
